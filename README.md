# AI Analytics Review

База знаний для продукта предварительного ревью технических заданий на потоки и витрины данных. Название рабочее. MTS рассматриваем как первого клиента, а применимость к другим компаниям проверяем в ходе продуктового анализа.

Состояние на 2026-09-03: собраны исходные материалы, сформулированы рабочие гипотезы и порядок их проверки. Сохранена и разобрана транскрибация Q&A с MTS, подготовлены предварительные портреты пользователя и покупателя. Отдельные проблемные интервью, эксперименты и реализация продукта ещё не проводились в рамках этой базы.
