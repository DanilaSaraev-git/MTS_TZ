# AI Analytics Review

База знаний для продукта предварительного ревью технических заданий на потоки и витрины данных. Название рабочее. MTS рассматриваем как первого клиента, а применимость к другим компаниям проверяем в ходе продуктового анализа.

Состояние на 2026-09-03: собраны исходные материалы, сформулированы рабочие гипотезы и порядок их проверки. Сохранена и разобрана транскрибация Q&A с MTS, подготовлены предварительные портреты пользователя и покупателя. Подготовлен внешний обзор автопроверок требований перед разработкой. Отдельные проблемные интервью, эксперименты и реализация продукта ещё не проводились в рамках этой базы.

## Реализация и эксперименты

Папка `implementation/` предназначена для реализации. Первый выделенный контур — [план PoC ревью ТЗ](implementation/poc/PLAN.md): переносимый навык для AI-агентов с локальными скриптами. Подготовлен план; сам навык ещё не реализован. Обсуждавшийся MVP переименован в proof of concept по решению [D-10](knowledge/decisions.md).

PoC фиксирует одну экспериментальную конфигурацию. Общий маршрут развития описан в [таймлайне и workflow](knowledge/roadmap.md): этапы после PoC находятся в статусе `planning` и могут меняться по мере добавления, уточнения или исключения гипотез. Клиентские материалы, включая результаты экспериментов MTS, сохраняются в `MTS/`.
