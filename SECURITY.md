# Security policy

Не публикуйте секреты, реальные клиентские документы или сведения об уязвимости в открытом issue.

Для сообщения об уязвимости используйте GitHub Private Vulnerability Reporting в разделе Security репозитория. Если эта функция недоступна, сначала запросите у владельца репозитория приватный канал связи без публикации технических деталей.

Поддерживаемая версия до первого релиза — текущая ветка `main`. Численные сроки реакции пока не установлены.
