# Принципы проекта для Spec Kit

Этот файл — указатель для команд Spec Kit. Единственный источник общих инструкций проекта — [AGENTS.md](../../AGENTS.md).

Перед составлением спецификации, плана, задач или проверкой Constitution Check прочитай `AGENTS.md` и указанные там документы, относящиеся к текущей задаче. Проверяй соответствие принципам по этому источнику.

Изменения общих правил вносятся в `AGENTS.md`; этот файл сохраняется как ссылка без отдельной копии принципов. Принятые продуктовые решения находятся в [реестре решений](../../knowledge/decisions.md).
