## Как использовать наблюдения

На интервью попросить эксперта оценить полезность каждого кандидата, указать недостающий внешний контекст и отметить артефакты обезличивания. Для подтверждённого замечания сохранить решение, причину и ожидаемое уточнение, не придумывая бизнес-правила за автора.

Отдельно проверить достаточность описания расположения источников, расписания, объёмов и расчёта полей по приоритетам стр. 1. Отсутствие конкретных адресов за нейтральными заглушками не является автоматически подтверждённым дефектом.

Наблюдения уже основаны на всех трёх примерах: эти документы пригодны для обсуждения и настройки, но не для заявления независимого качества по тем же замечаниям.
