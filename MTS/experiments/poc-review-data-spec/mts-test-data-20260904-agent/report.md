## Замечания

### F-001. Не определена граница задержки

**Приоритет:** Высокий. Влияет на архитектуру потока и приёмочные критерии.

**Проблема:** В одном описании соседствуют задержка «< 1 мин», стриминг «≈ 0 сек» и часовые партиции без точек измерения.

**Почему:** Значения могут относиться к разным участкам, но документ не позволяет проверить реализацию и SLA.

**Вопрос:** Для каждого ограничения укажите начальное и конечное событие измерения и момент доступности данных потребителю.

**Статус человека:** Не рассмотрено

Основания:

- [Тестовые данные.pdf, стр. 2](sources/s001.pdf): «Задержка: < 1 мин» (`s001-p0002-text`).
- [Тестовые данные.pdf, стр. 2](sources/s001.pdf): «Стриминг в реальном времени (задержка ≈ 0 сек)» (`s001-p0002-text`).
- [Тестовые данные.pdf, стр. 2](sources/s001.pdf): «Инкрементная загрузка по часовым партициям» (`s001-p0002-text`).

### F-002. Не назван список очищаемых полей

**Приоритет:** Высокий. Неопределённая область преобразования может изменить значения ключевых полей.

**Проблема:** Фраза «Из этих полей» не имеет в предоставленном фрагменте явного списка полей.

**Почему:** Разработчик не может однозначно определить область преобразования; это также может быть потерей при обезличивании.

**Вопрос:** Какие поля очищаются? Как обрабатывать пустую строку, NULL и значение только из нулей? Не удалён ли список при обезличивании?

**Статус человека:** Не рассмотрено

Основания:

- [Тестовые данные.pdf, стр. 5](sources/s001.pdf): «Из этих полей удаляются лидирующие нули до первого значимого символа.» (`s001-p0005-text`).

### F-003. Не определена семантика часового сдвига

**Почему:** Одинаковое значение времени может быть преобразовано в разные моменты.

**Вопрос:** Из какого времени в какое выполняется перевод, к каким полям он применяется и как соотносятся FIELD_TIME_ZONE_SHIFT и FIELD_TIMEZONE_CALC?

**Статус человека:** Не рассмотрено

Основания:

**Вопрос:** Резервные правила применяются до отбора ненулевой пары или только если полное совпадение не найдено? Что делать, если оба значения нулевые?

**Вопрос:** Верно ли, что ключ группировки — только FIELD_REGION_NAME и FIELD_VENDOR_NAME, а FIELD_USERS_CNT вычисляется после группировки?
