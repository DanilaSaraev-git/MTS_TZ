# Прогоны PoC review-data-spec для MTS

Клиентские входы, профиль и результаты. Они не входят в переносимый навык. `profile.json` — черновая конфигурация из постановки и текущей базы, не утверждённый MTS стандарт.

Каждая папка запуска содержит неизменяемый снимок источников, производное извлечение, agent report, техническую валидацию, читаемый отчёт и протокол. Тестовые данные уже использованы при настройке и не являются независимым контрольным набором.
