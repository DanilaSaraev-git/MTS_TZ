# Эксперименты MTS

Здесь сохранены два разных прогона ревью. Они имеют разное происхождение, формат подготовки и число фрагментов, поэтому не объединяются и не считаются повторениями одного измерения.

| Эксперимент | Происхождение | Результат | Ограничение |
| --- | --- | --- | --- |
| [Direct agent review](direct-agent-review/README.md) | Ручной агентный проход по клиентским документам и текущему контексту базы | 172 фрагмента, 16 вопросов, техническая валидация `complete` | Нет независимой экспертной разметки; использованные документы не являются контролем |
| [Portable skill review](poc-review-data-spec/README.md) | Прогон через переносимый PoC `review-data-spec` с зафиксированным профилем и bundle | 141 фрагмент, отдельные protocol/report/validation | Другой pipeline и снимок контекста; нельзя смешивать метрики с direct review |

Оба результата являются клиентскими материалами. Техническая валидация подтверждает структуру и привязки, но не правильность замечаний, экономию или результат пилота.
