# Direct agent review

Прямой агентный прогон от 2026-09-04 сохранён без объединения с PoC-прогоном. Канонический результат: [report.md](2026-09-04-mts-test-data/report.md); рядом находятся входной снимок, извлечения и validation.

Прогон подготовил 172 фрагмента и 16 адресных вопросов. Его происхождение и pipeline отличаются от [`poc-review-data-spec`](../poc-review-data-spec/README.md), где переносимый skill подготовил 141 фрагмент. Сопоставлять количества как метрику качества нельзя без общей разметки и контролируемой процедуры.
